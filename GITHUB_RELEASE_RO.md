# v0.37.24 — Recuperare Zigbee2MQTT cu pauză explicită

Actualizare a integrării Aqara M1S, construită din arhiva 0.37.23. După o
oprire neașteptată, integrarea verifică din nou coordonatorul și recuperează
Zigbee2MQTT cu un număr limitat de încercări. Bifa Pauză rămâne la alegerea
utilizatorului. Pentru o oprire de mentenanță, folosește Pauză din integrare.

Pentru instalare și revenire vezi [INSTALL_RO.md](INSTALL_RO.md).
Pentru verificările locale vezi VALIDATION.txt, TEST_REPORT.json și TEST_LOG.txt.
Arhiva păstrează structura repository-ului integrării pentru instalare manuală
sau distribuție ulterioară. Nu a fost publicată sau instalată în Home Assistant.
