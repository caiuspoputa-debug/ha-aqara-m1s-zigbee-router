Staged Router deployment rule:
- Stage the upgrade with MQTT_IO_ENABLED=0.
- Install v0.36.1 in Home Assistant and restart Home Assistant.
- Only then run /data/m1s_router/mqtt_io_activate.sh.
- Activation requires successful initial RGB state, validated A6 lux and
  telemetry publication. Failure stops and disables the agent.

Isolation guarantees:

  old temporary TCP UART tunnel.
- Router MQTT subscribes only to RGB set and lux refresh topics. It contains no
  radio, WAV, play, pause, stop, volume or PCM transport command.
- Router rejoin uses a temporary, 90-second self-recovering maintenance window.
- Coordinator RGB/lux remains MQTT-only through its isolated sideband socket.
