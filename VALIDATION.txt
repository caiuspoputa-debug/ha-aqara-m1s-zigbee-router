Staged deployment rule:
- Install the hub agent with MQTT_IO_ENABLED=0.
- Install v0.35.0 in Home Assistant and restart Home Assistant.
- Only then run /data/m1s_coordinator/mqtt_io_activate.sh.
- The activation script requires successful initial state/lux/telemetry and an
  established Z2M session; otherwise it stops and disables the agent.

Isolation guarantees:
- Coordinator RGB/lux is MQTT-only from Home Assistant and never falls back to
  Router A5/A6 or a Telnet sideband command.
- The agent talks only to /tmp/m1s-coordinator-io.sock. It never opens UART or
  TCP port 1886 and cannot issue Coordinator OFF.
- Stored-WAV MQTT commands prepare/stop only the dedicated ports 12347/12348,
  FIFO and exact PID files already used by the confirmed sound implementation.
- Radio/group audio remains on the existing transport and is never sent over MQTT.
- Router behavior is unchanged.
